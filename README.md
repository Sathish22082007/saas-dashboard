# SaaS Dashboard

A modern SaaS admin dashboard built with Tailwind CSS featuring analytics, user management, and data visualization.

## Features

- **Analytics Dashboard** — Real-time metrics, revenue charts, and user growth tracking
- **User Management** — User table with search, filtering, and role management
- **Data Visualization** — Interactive charts (line, bar, donut) using Chart.js
- **Dark Mode** — Full dark mode support with system preference detection
- **Responsive Design** — Mobile-first layout that works across all devices

## Tech Stack

- HTML5 / CSS3 / JavaScript
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- [Chart.js](https://www.chartjs.org/) for data visualization
- Inter & JetBrains Mono fonts

## Usage

Open `saas_dashboard.html` in any modern browser. No build step required.

```bash
open saas_dashboard.html
```
